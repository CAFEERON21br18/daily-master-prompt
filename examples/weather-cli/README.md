# Example: weather-cli, after 3 days

What `/daily-master-prompt:create` writes into a project, shown after three daily sessions. The project is fictional; the files are real examples of the format.

| File | Look at it for |
|---|---|
| [`DAILY_PROMPT.md`](DAILY_PROMPT.md) | The one file a fresh session executes, with a dated addendum at the bottom |
| [`BACKLOG.md`](BACKLOG.md) | 5 items done with commit hashes, 1 blocked, the next ones in order |
| [`DEVLOG.md`](DEVLOG.md) | One entry per day: plan, done, blocked, what was learned |
| [`HANDOFF.md`](HANDOFF.md) | Where things stand right now, and the next 3 actions |
| [`QUESTIONS.md`](QUESTIONS.md) | One answered question (applied) and one waiting for you |
| [`APPROVALS.md`](APPROVALS.md) | A new dependency waiting for your yes/no |

Every morning the user types one line:

```
Read examples/weather-cli/DAILY_PROMPT.md and execute it.
```
